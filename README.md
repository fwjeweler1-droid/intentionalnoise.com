# IntentionalNoise.com — music and releases storefront

**Network reference:** [IN-NET-2026-11-08-SYNC-01](https://github.com/fwjeweler1-droid/connect.intentionalnoise.info/blob/main/NETWORK_SYNC_CHECKPOINT_2026-11-08.md)  
**Repo placement marker:** [network-sync.json](network-sync.json)

This site is connected to the Intentional Noise family for navigation and promotion, but is **NOT** a fifth live member-profile directory and **NOT** a separate member authentication or booking database. Artists register through Connect; discovery/bookings go to IneedaGig; published artist pages live at IntentionalNoise.band and the two public directories.

**Music authority:** The authoritative `Music_Project_Command_Center.xlsx` in the user’s Library and approved music assets govern releases and promotional materials. Network synchronization checkpoints must not override MPCC approvals, media lineage or distribution status.

**Status:** Existing site deployment is independent; no music storefront or MPCC records were changed by the network checkpoint. Separate live validation applies.
